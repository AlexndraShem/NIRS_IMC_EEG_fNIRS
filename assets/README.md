# assets/

Ноутбуки Jupyter (`.ipynb`) с воспроизводимым ходом решения. Число файлов свободное.

По смыслу желательно покрыть: EDA → предобработка → признаки/классификатор →
онлайн-симуляция (`run.py`/`score.py` → `results/metrics/`) → сравнение ЭЭГ / NIRS / гибрид.

Сохраняйте выводы ячеек. Не коммитьте `.mat`. Метрики сдачи — только через замороженный каркас.

## Ноутбуки команды HORMIGAS

Все ноутбуки выполнены, выводы ячеек сохранены. Они используют код решения из `../solution/`
(тот же, что запускает судья) и сохранённые прогоны из `../results/`.

| ноутбук | что внутри | время на 1 ядре |
|---|---|---|
| [`01_data_eda.ipynb`](01_data_eda.ipynb) | структура 56 сессий, баланс классов, протокол, монтаж; ERD мю/бета над C3/C4; запаздывающий ответ HbO по полушариям → выбор признаков | ≈ 0.5 мин |
| [`02_causal_pipeline.ipynb`](02_causal_pipeline.ipynb) | сетка окон ≡ судейской; проверка причинности фильтров (поток ≡ целиком, будущее не влияет на прошлое, контраст с `sosfiltfilt`); АЧХ фильтров ЭЭГ/NIRS; боевой `OnlineClassifier` на потоке: вероятности ЭЭГ / NIRS / гибрида во времени, охрана ВЧ-артефактов, тайминги; деградация без NIRS | ≈ 2 мин |
| [`03_online_simulation.ipynb`](03_online_simulation.ipynb) | живой прогон официальных `run.py` → `score.py`; официальная (хронологическая) цифра и протоколы LOSessO / LOSubjO; ЭЭГ-only vs NIRS-only vs гибрид (выигрыш слияния, тест Уилкоксона); матрицы ошибок; дообучение по блокам; тайминги | ≈ 3 мин (`RUN_ALL=True` — ≈ 40 мин) |
| [`04_training_and_history.ipynb`](04_training_and_history.ipynb) | состав `solution/artifacts/`, как и на чём обучена каждая часть, команды полной пересборки; вклад предобученных пулов; история балла по этапам | ≈ 1.5 мин |

Запуск (из корня репозитория, окружение — `DEPLOY.md`, плюс `jupyter`, `matplotlib`, `pandas`):

```bash
export HORMIGAS_DATA=<каталог с *.mat>        # по умолчанию data/Data (распакованный data.zip)
jupyter nbconvert --to notebook --execute --inplace assets/*.ipynb
```

Ноутбук 03 в разделе 1 прогоняет каркас с артефактами сдачи. Они обучены на всех train-сессиях, поэтому
цифры там завышены, и раздел проверяет только контракт и тайминги. Честные цифры считаются тем же каркасом
по протоколам с подменой артефактов: хронологическим, LOSessO и LOSubjO. Их прогоны лежат в `results/`,
команды для пересборки — в `report/REPORT.md`, раздел «Воспроизведение».
