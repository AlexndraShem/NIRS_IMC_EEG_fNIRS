# Описание данных

## Обзор

Обучающий набор содержит **56 файлов** `.mat` (одна сессия = один файл) от **14 испытуемых**:
`N01, N02, N03, N06, N08, N09, N10, N11, N13, N14, N15, N16, N17, N18`.

Формат имени: `YYYY.MM.DD.HH.MM.SS_NXX.mat`, например `2025.12.01.16.04.01_N01.mat`.

Длительность сессии ≈ 596–598 с, **7 блоков** инструкций. Данные размещены в бакете Object Storage и монтируются в DataSphere через S3 Connector (см. [DEPLOY.md](../DEPLOY.md)).

Необязательный пример чтения файла: [`example.py`](../example.py) в корне репозитория (`python example.py <session.mat>`). Использовать не обязательно.

## Структура файла

```python
from scipy.io import loadmat
mat = loadmat(path, simplify_cells=True)
# mat["EEG"], mat["NIRS"]  — NIRS может отсутствовать
```

### EEG

| Поле | Размерность | Назначение |
|------|-------------|------------|
| `EEG.Raw` | отсчёты × 21 | Необработанный сигнал ЭЭГ (ADC-отсчёты) |
| `EEG.States` | отсчёты × 1 | Метки классов (0, 1, 2, 3) |
| `EEG.Blocks` | отсчёты × 1 | Номер блока (1…7) |
| `EEG.Frq` | скаляр | Частота дискретизации, **всегда 250 Гц** |

Порядок электродов (0-based колонки):

```
0:c4  1:rpa  2:f8  3:p8  4:f4  5:p4  6:fp2  7:o2  8:cz  9:pz
10:fz 11:o1 12:fp1 13:p3 14:f3 15:p7 16:f7 17:lpa 18:c3 19:c7 20:c8
```

Значения — некалиброванные ADC-отсчёты с постоянной составляющей порядка 10⁸–10⁹; у части каналов возможен клиппинг (размах до ~10¹⁰). Перед фильтрацией обычно требуется удаление тренда / полосовая фильтрация.

### NIRS

| Поле | Размерность | Назначение |
|------|-------------|------------|
| `NIRS.HbO` | отсчёты × 18 | Концентрация HbO |
| `NIRS.HbR` | отсчёты × 18 | Концентрация HbR |
| `NIRS.States` | отсчёты × 1 | Метки классов |
| `NIRS.Blocks` | отсчёты × 1 | Номер блока (1…7) |
| `NIRS.Frq` | скаляр | Частота дискретизации (см. ниже) |
| `NIRS.Frame` | отсчёты × 1 | Индекс отсчёта ЭЭГ (1-based), соответствующий данному отсчёту NIRS |

Колонка *i* соответствует **одному и тому же** положению источник–детектор во всех сессиях (позиция согласована между тремя аппаратными конфигурациями, использовавшимися при записи).

#### Частота NIRS

- **12.5 Гц** — в 52 сессиях;
- **3.90625 Гц** — в `2025.12.09.12.52.43_N01.mat` и `2026.02.19.13.23.35_N13.mat`.

Не зашивайте 12.5 в код: читайте `NIRS.Frq`.

#### Сессии без NIRS

В двух файлах поле `NIRS` **отсутствует**:

- `2025.12.18.12.09.22_N03.mat`
- `2025.12.18.15.02.14_N02.mat`

Решение должно корректно деградировать до ЭЭГ-only (не падать).

`NIRS.Frame` содержит повторяющиеся значения (пакетная выдача прибора). Для синхронизации используйте `Frame` как индекс в шкале ЭЭГ.

## Метки состояний

| Метка | Состояние | Участие |
|-------|-----------|---------|
| 0 | Подготовка и промежуточные интервалы | Не классифицируется |
| 1 | Покой | Класс 1 |
| 2 | Представление раскрытия левой кисти | Класс 2 |
| 3 | Представление раскрытия правой кисти | Класс 3 |

## Парадигма сессии

- 7 блоков; в каждом блоке: 4 пробы моторного воображения (по 2 на каждую кисть) и чередующиеся интервалы покоя.
- Подготовка к инструкции: **1.5 с** (метка 0); выполнение задачи: **9 с** (метки 1/2/3).
- Блок 1 используется только для первичного обучения и **не оценивается**.
- Классификация: окно **1 с**, шаг **250 мс**. Оцениваются только окна, целиком лежащие внутри однородного сегмента `States ∈ {1,2,3}` и вне блока 1.

Ожидаемый объём оценённых окон на сессию: ≈ 1544–1553; баланс классов ≈ 0.50 / 0.25 / 0.25 (покой / ЛК / ПК).

## Экспериментальный контекст (кратко)

Данные получены в слепом рандомизированном исследовании гибридного ИМК–ЭС (BCI–FES) у здоровых добровольцев (РНИМУ им. Н. И. Пирогова). Участники выполняли кинестетическое представление раскрытия кисти; при правильном распознавании запускалась функциональная электростимуляция разгибателей запястья. Подробности — в [TZ.md](TZ.md), раздел «Описание эксперимента».
