# neuro_train — открытые сессии хакатона (ЭЭГ + NIRS)

- **Источник:** `~/datasets/hackatons/medic/data.zip` → распакован в `~/datasets/hackatons/medic/data/`
  (в проекте — симлинк `data/raw`). Оригинал: бакет `storage.yandexcloud.net/neuralinterfaces-train/Data/`.
- **Состав:** 56 сессий `data/raw/Data/<YYYY.MM.DD.HH.MM.SS>_N<id>.mat` (MATLAB v5, читается
  `scipy.io.loadmat`), `data/raw/Montage.mat`, `data/raw/example.py`. 1.2 ГБ.
- **Участники (14):** N01(3), N02(4), N03(4), N06(4), N08(4), N09(4), N10(4), N11(4), N13(4),
  N14(5), N15(4), N16(4), N17(4), N18(4) — в скобках число сессий.
- **Сводная таблица по сессиям:** `data/sessions_summary.csv` (`src/scripts/survey_sessions.py`).
- **Загрузчик:** `src/dataset/io.py` (`load_session`, кэш `data/cache/*.npz`);
  сетка окон и метрики — `src/dataset/windows.py`.

## Формат

| поле | форма | примечание |
|---|---|---|
| `EEG.Raw` | (≈149 000, 21) float64 | 250 Гц, ≈597 с. Масштаб сильно различается между сессиями (медиана std приращений от 3e5 до 6e8), большой DC — нужна причинная нормировка |
| `EEG.States` | (n,) uint8 | 0 подготовка, 1 покой, 2 левая, 3 правая |
| `EEG.Blocks` | (n,) uint8 | 1…7 |
| `NIRS.HbO/HbR` | (≈7460, 18) | 12.5 Гц (2 сессии — 3.90625 Гц: `2025.12.09.12.52.43_N01`, `2026.02.19.13.23.35_N13`) |
| `NIRS.States/Blocks` | (m,) | совпадают с `EEG.States[Frame-1]` на 100 % |
| `NIRS.Frame` | (m,) int32 | 1-based индекс отсчёта ЭЭГ; отсчёт NIRS доступен, когда пришёл ЭЭГ-отсчёт `Frame-1` |
| `Montage.EEG_labels` | 21 | fp1 fp2 f3 f4 c3 c4 p3 p4 o1 o2 f7 f8 c7 c8 p7 p8 lpa rpa fz cz pz (c7/c8 ≈ T3/T4). ⚠️ **Не порядок столбцов `EEG.Raw`!** По ответу кейсодержателя столбец 0 = C4, 18 = C3 (подтверждено ERD); полный список — `meta["eeg_channel_names"]` судьи |
| `Montage.EEG_positions`, `NIRS_positions` | (21,2), (18,2) | 2D-координаты; NIRS — 8 каналов над правой, 8 над левой моторной корой, 2 около Cz |

- **Без NIRS (поле пустое):** `2025.12.18.12.09.22_N03`, `2025.12.18.15.02.14_N02` → нужна
  деградация до ЭЭГ-only.
- **В `example.py`** упоминается `NIRS.wl1` — в выданных файлах его нет, есть только HbO/HbR.

## Структура сессии

- 7 блоков × 8 сегментов по 9 с: **покой и задача строго чередуются**
  (0→1→0→{2|3}→0→1→0→{2|3}…), по 2 левых и 2 правых на блок; перед каждым сегментом
  подготовка 1.5 с (state 0, в начале блока — дольше).
- На сессию: 28 сегментов покоя (63 000 отсчётов), 14 левых, 14 правых.
- Окна 1 с / шаг 250 мс, целиком внутри однородного сегмента: ≈33 окна на сегмент,
  ≈1790 на сессию, из них оцениваются блоки 2–7 (≈1540). Баланс классов 2:1:1.

## Качество ЭЭГ

- Сильная наводка 50 Гц и 100 Гц; пики на 25/75 Гц (вероятно, ФЭС 70 Гц / интермодуляция).
- В большинстве сессий 1–6 «мёртвых/шумных» каналов (дисперсия на порядки выше/ниже
  медианы): чаще всего столбцы 7, 11, 16, 17, 19, 12 (имена по Montage p4, f8, lpa, rpa, cz, c7 — неверны). Набор своих для каждой сессии.

## Подводные камни / риски

- Чередование покой/задача и фиксированный тайминг — это структура протокола. Явно
  использовать расписание (часы, счётчик сегментов) — сомнительно с точки зрения правил;
  пока **не используем**.
- Во время подготовки показывается стрелка направления — возможны саккады/ЭОГ в лобных каналах.
  Испытуемых просили смотреть в центр, ЭОГ не писали (консультация 2026-09-23). Проверку надо
  делать по правильным именам каналов (см. выше).

## Протокол теста (консультация 2026-09-23)

- Закрытый тест: по одной новой сессии от каждого участника; можно использовать все train-сессии,
  включая того же участника (`meta["subject"]`). Для метрик на train — модели по более ранним сессиям.
- Формат вызовов судьи — `QA.md` §1.2.
