# eeg_ts_pool_online — финальный ЭЭГ-декодер: TS фильтр-банка \+ within-sLDA × кросс-субъектный пул

- **Дата:** 2026-09-22. Окружение `kaggle` (python 3.11), CPU; GPU использовался только для
  проверки MLP-пула (не вошёл в финал).
- **Код:** `src/eeg/cache.py`, `src/eeg/common.py`, `src/eeg/online.py` (потоковая модель),
  `src/eeg/final.py` (оценка \+ артефакты), `src/eeg/simulate.py` (потоковая симуляция \+ тайминги),
  `src/eeg/analyze.py`, `src/eeg/exp_cross.py`, `src/eeg/exp_cross2.py`, `src/eeg/exp_clf.py`.
- **Признаки:** `data/features/eeg_fb64/*.npz` — ковариации 7 полос × окна 1/2/4 с, сырое ЭЭГ
  читается во **float64** прямо из `.mat` (`src.eeg.cache.load_raw64`), строки выровнены с
  `data/features/v1_win1/<сессия>.npz`.
- **Вероятности:** `data/probs/eeg_ts2s_all.pkl` (основная), `eeg_ts2s.pkl` (без лобных),
  `eeg_ts1s.pkl` (окно 1 с), плюс `*_within.pkl` / `*_pool.pkl` — компоненты смеси.
- **Артефакты пула:** `data/features/eeg_models/pool_<имя>_<участник>.npz` (leave-subject-out,
  для честной оценки) и `pool_<имя>_all.npz` (обучен на всех 56 сессиях — для сдачи).

## Модель

1. **Признак окна.** Причинная фильтрация (HP 1 Гц \+ notch 50 Гц, 7 полос), ковариация по
   последним 2 с; поканальная нормировка (медиана дисперсий прошлых окон, пол для «мёртвых»
   каналов) \+ shrinkage 1e-2; касательное пространство относительно референса сессии
   (лог-евклидово среднее прошлых окон, по полосам). Размерность: 21 канал × 7 полос = 1617
   (15 каналов → 840).
2. **within-sLDA.** LDA с фиксированным shrinkage **0.8** (не `auto`!) на TS-признаках блоков \< b.
   Сильный shrinkage даёт \+2.9 балла к `auto` и, главное, убирает чудовищную переуверенность
   (медианный разрыв логитов у `auto` ≈ 20 нат), из-за которой смесь с любым вторым источником
   не работала.
3. **Кросс-субъектный пул.** Логистическая регрессия (C=0.01, `class_weight="balanced"`,
   стандартизация) на TS-признаках всех сессий **других участников**; каждая сессия пула
   рецентрирована по собственному референсу — это и есть «выравнивание» (римановo
   рецентрирование), которое делает признаки сопоставимыми между людьми.
4. **Смесь.** `P ∝ P_within^(1-a) · P_pool^a`, a = 0.8, лог-вероятности клиппируются снизу 1e-9.
   Выход — **без** сглаживания по времени (сглаживание и слияние с NIRS — на стороне координатора).

|вариант|minF1|recall|60F\+30P|
|:---|:---|:---|:---|
|stage0 baseline (1 с, logvar, within sLDA auto)|0\.424|0\.555|42\.1|
|within sLDA(0.8), 2 с, 15 каналов|0\.457|0\.603|45\.5|
|within sLDA(0.8), 2 с, 21 канал|0\.464|0\.607|46\.1|
|только пул LR (leave-subject-out), 2 с, 21 канал|0\.420|0\.555|41\.8|
|смесь, окно 1 с, 15 каналов (`eeg_ts1s`)|0\.445|0\.587|44\.3|
|смесь, окно 4 с, 15 каналов|0\.479|0\.620|47\.4|
|смесь, окно 2 с, 15 каналов (`eeg_ts2s`)|0\.481|0\.622|47\.5|
|**смесь, окно 2 с, 21 канал (`eeg_ts2s_all`)**|**0.501**|**0.633**|**49.1**|

Отдельно (окно 2 с, 15 каналов): вес смеси a = 0.5 / 0.6 / 0.7 / 0.8 → 46.4 / 46.7 / 47.0 / 47.5;
для 21 канала → 47.2 / 47.6 / 48.2 / 49.1. Пул-MLP (GPU, 256/512 нейронов) как второй источник
хуже LR (44.7 против 47.5 в смеси); «рекалибровка» пул-логитов по прошлым блокам текущей сессии
только вредит (44.5).

Детализация лучшей модели (`eeg_ts2s_all`): F1 по классам покой/левая/правая = 0.837 / 0.537 /
0.525, точность различения левая-vs-правая 0.653; recall по блокам 2…7 = 0.514, 0.590, 0.638,
0.672, 0.674, 0.711 (виден вклад дообучения: пул важнее всего на блоке 2, дальше вес within растёт
сам собой за счёт качества). Сдвиг лог-приора задач на \+0.4 даёт ещё \+0.5 балла (49.6), но это
подгонка одного параметра на всей выборке — в основной выход не включена, координатор может
сделать её при слиянии с NIRS.

**Лобные каналы:** 21 канал против 15 без fp1/fp2/f7/f8(\+lpa/rpa) — 49.1 против 47.5.
Классификатор только по лобным каналам различает левую/правую с точностью 0.562 (почти случай),
т.е. основной сигнал не глазной; но вклад \~1.6 балла частично может быть артефактным.
Поэтому сданы обе версии.

## Онлайн-реализация (`src/eeg/online.py`, класс `OnlineEEG`)

Хранимое состояние: `zi` префильтра и 7 полосовых фильтров; кольцевой буфер отфильтрованного
сигнала 2 с × 7 полос × C каналов; история ковариаций окон на сетке 250 мс (до \~1800 матриц
7×21×21 за сессию, ≈ 21 МБ); `RefState` (масштабы каналов \+ 7 матриц отбеливания); коэффициенты
within-sLDA и пул-LR.

- `push(chunk)` — причинная фильтрация чанка с сохранением состояния, обновление буфера,
  в точках сетки 250 мс — сохранение ковариации окна.
- `predict_proba()` — ковариация текущего буфера → TS → лог-вероятности within и пула → смесь.
- `fit_block(b, states_блока)` — добавить метки; отобрать окна, целиком лежащие в однородном
  сегменте States ∈ \{1,2,3\} завершённых блоков; пересчитать референс (по каждому 4-му окну —
  окна перекрываются на 87.5 %) и обучить sLDA (по каждому 2-му окну). Прореживание не стоит
  ничего по качеству (45.6 → 45.5 балла) и ускоряет fit в 2 раза.

**Времена** (эта машина под нагрузкой \~15, потоковая симуляция `src/eeg/simulate.py`,
чанки 100 мс, батч-`eigh` в 4 потока):


|вариант|predict (среднее / макс)|fit_block блоки 1…7|
|:---|:---|:---|
|15 каналов (`eeg_ts2s`)|3\.2 / 10.7 мс|0\.12 … 0.57 с|
|21 канал (`eeg_ts2s_all`)|5\.1 / 8.9 мс|0\.40 … 1.28 с|

Бюджет ТЗ (predict \< 0.2 с, fit_block \< 1.5 с) выдержан. Если на машине жюри окажется медленнее,
для 21-канальной версии достаточно увеличить прореживание до `ref_stride=8, train_stride=4`:
fit_block падает примерно вдвое при 48.7 балла вместо 49.1.

**Сверка потока с оффлайн-оценкой:** `python -m src.eeg.simulate ts2s_all 2 all 3` —
\|P_stream − P_offline\| ≤ 3e-6, совпадение argmax 100 % на всех проверенных сессиях, т.е.
сохранённые вероятности ровно то, что выдаст онлайн-модель.

## Воспроизведение

```bash
python -m src.eeg.cache --f64                       # data/features/eeg_fb64
python -m src.eeg.final 2 all      0.8 0.8 ts2s_all <scratch>   # основная модель
python -m src.eeg.final 2 nofront  0.8 0.8 ts2s     <scratch>   # без лобных каналов
python -m src.eeg.final 1 nofront  0.8 0.8 ts1s     <scratch>   # окно 1 с
python -m src.eeg.simulate ts2s_all 2 all 3         # потоковая сверка и тайминги
python -m src.eeg.analyze eeg_ts2s_all eeg_ts2s eeg_ts1s
```

`final.py` сохраняет `data/probs/eeg_<имя>.pkl` = \{сессия: (n\_окон, 3)\} с NaN на блоке 1,
порядок строк — как в `data/features/v1_win1/<сессия>.npz`, столбцы — P(покой), P(левая), P(правая).
