# eeg_within_sweep — within-session ЭЭГ: длина окна, каналы, полосы, признаки

- **Дата:** 2026-09-22. Окружение `kaggle` (python 3.11), CPU (10 процессов), без GPU.
- **Код:** `src/eeg/cache.py` (кэш ковариаций), `src/eeg/common.py` (TS/logvar, оценка),
  `src/eeg/exp_within.py`, `src/eeg/exp_frontal.py`, `src/eeg/exp_csp.py`.
- **Данные:** `data/features/eeg_fb/*.npz` — ковариации фильтр-банка по окнам сетки 250 мс
  (те же `ends`, что в `data/features/v1_win1`, строки выровнены).

## Сетап

Причинная цепочка (полностью эквивалентна потоковой, проверено в `src/eeg/simulate.py`):
вычитание первого отсчёта → HP 1 Гц \+ notch 50 Гц (`sosfilt`) → 7 полос Баттерворта 4-го порядка
(4-8, 8-10, 10-13, 13-18, 18-24, 24-30, 8-30 Гц) → ковариация по последним `win` секундам.
Нормировка ковариаций поканально (медиана дисперсий по прошлым окнам) \+ shrinkage 1e-2;
`ts` — касательное пространство с референсом = лог-евклидово среднее прошлых окон,
`logvar` — только диагональ. Классификатор — sLDA (`shrinkage="auto"`), обучение только на
блоках \< b текущей сессии, оценка — блоки 2–7, метрики ТЗ, среднее по сессиям.

Наборы каналов: `all` (21), `nofront` (15: без fp1/fp2/f7/f8 и lpa/rpa), `sm` (11 сенсомоторных).

|**2 с**|logvar|all|7|0\.449|0\.577|44\.2|

|2 с|ts|nofront|7|0\.436|0\.578|43\.5|

|4 с|logvar|all|7|0\.437|0\.568|43\.3|

Baseline stage0 (1 с, logvar, sLDA) — 42.1. Выводы:

- **Длина истории:** 2 с заметно лучше 1 с (\+2.4 балла), 4 с — уже хуже 2 с. Окно оценки
  остаётся 1-секундным по ТЗ, но признак считается по последним 2 с сигнала — это причинно.
  *Нюанс для жюри:* при 2-секундной истории в начале сегмента окно частично захватывает
  предшествующую паузу/подготовку (показ стрелки). Это не «подглядывание» в будущее и не
  использование расписания, но реакция на стимул может вносить вклад; поэтому сохранена и
  1-секундная версия модели (см. `docs/experiments/eeg_ts_pool_online.md`).
- **Фильтр-банк** заметно лучше одной широкой полосы 8-30 Гц (\+3 балла).
- **Касательное пространство** лучше logvar на 0.5–1 балл (и сильнее по recall).

## Лобные каналы (глазные артефакты), окно 2 с, 6 полос


|каналы|minF1|recall|60F\+30P|F1 (покой, левая, правая)|точность левая/правая|
|:---|:---|:---|:---|:---|:---|
|только fp1,fp2,f7,f8 (ts)|0\.372|0\.520|38\.0|0\.73 / 0.44 / 0.38|0\.562|
|без лобных (15 каналов, ts)|0\.431|0\.572|43\.1|0\.79 / 0.46 / 0.47|0\.604|
|все 21 (ts)|0\.445|0\.585|44\.2|0\.81 / 0.48 / 0.47|0\.625|

Итог: **модель не сводится к ЭОГ** — по одним лобным каналам левая/правая различаются лишь
на уровне 0.56 (случай — 0.5), тогда как по сенсомоторным — 0.60–0.62. Но лобные каналы всё же
дают \+1.1–1.6 балла, часть из которых может быть артефактной (саккады на стрелку). Обе версии
(21 канал и 15 без лобных) сохранены как отдельные наборы вероятностей.

## FBCSP

`src/eeg/exp_csp.py` — FBCSP (OvR \+ пара левая/правая, m фильтров с каждого края, shrinkage
ковариаций классов) \+ sLDA. На этих данных проигрывает касательному пространству
(окно 2 с, 21 канал, float64-кэш: m=2, shrink 0.1 → minF1 0.433 / recall 0.572 / **43.1**;
m=3, shrink 0.2 → 0.434 / 0.571 / 43.1 — против 45.0 у TS с sLDA `auto` и 46.1 у TS с sLDA 0.8):
при 4 пробах на класс в блоке 1 CSP-фильтры нестабильны, а TS-признаки с сильным shrinkage
устойчивее.

## Воспроизведение

```bash
python -m src.eeg.cache                 # data/features/eeg_fb (float32-кэш io.py)
python -m src.eeg.exp_within 2          # свип признак × каналы × полосы
python -m src.eeg.exp_frontal 2         # вклад лобных каналов
python -m src.eeg.exp_csp 2 all         # FBCSP
```
