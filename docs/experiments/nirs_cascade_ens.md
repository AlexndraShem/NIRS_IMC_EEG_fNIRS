# nirs_cascade_ens — NIRS-only декодер: каскад ансамблей sLDA

- **Дата:** 2026-09-22. Окружение `kaggle` (python 3.11), numpy/scipy/sklearn.
- **Данные:** 54 сессии с NIRS (2 сессии без NIRS пропущены), окна `data/features/v1_win1`
  (1 с / 250 мс, однородные сегменты), оценка — блоки 2–7, среднее по сессиям.
- **Протокол:** онлайн-порядок, для блока b модель обучена только на блоках < b той же сессии.
  Кросс-субъектный пул проверен (LOSO), в итоговую модель не вошёл (не дал прироста).

## Модель

1. **Предобработка** (причинно, `sosfilt` с zi = steady-state по первому отсчёту): 4 банка
   полосовых Баттервортов HbO/HbR: 0.005–0.1 (пор. 2), 0.01–0.2 (2), 0.02–0.3 (2), 0.01–0.5 Гц (3).
2. **Производные каналы (58):** 18 HbO + 18 HbR, 9 пар латерализации (левое − правое: канал i+8 − i,
   17 − 16) для HbO и HbR, глобальное среднее HbO/HbR, средняя латерализация HbO/HbR.
   Масштаб — std каждого канала по блоку 1 (с 20-й секунды), далее заморожен.
3. **Признаки окна:** значения в последнем доступном отсчёте NIRS (`Frame ≤ end`) и на лагах
   назад; режим `diff` = [x(t), x(t) − x(t−lag)…], `level` = [x(t−lag)…].
4. **Покой/задача:** 8 sLDA (lsqr, shrinkage Ledoit–Wolf, priors 0.5/0.5), средний логит p_t:
   каналы `chan` (36) или `all` (58), лаги (0,4,8,12) diff по всем банкам, (0,3,6,9,12) level,
   (0,1,2,4,6) diff.
5. **Левая/правая:** 4 sLDA на окнах задачи с позицией в сегменте ≥ 3 с (метки прошлых блоков
   используются только для отбора обучающих окон): `all` лаг 0 (0.01–0.2 и 0.02–0.3 Гц),
   `all` (0,3) diff (0.005–0.1), `chan` лаг 0 (0.01–0.2). Средний логит p_r.
6. P = [1 − p_t, p_t(1 − p_r), p_t·p_r].

Что пробовали и не взяли: полосы 0.005–0.1/0.02–0.3/0.01–0.5/НЧ 0.5 Гц по отдельности (±0.01),
только латерализационные/глобальные признаки (хуже: 0.32), только HbO (хуже), длинная история
уровней без разностей (хуже), отбор обучающих окон ≥ 2–4 с для покой/задача (хуже),
сдвиг порога покоя (±0.005), кросс-субъектный пул и его смеси, EMA-сглаживание (не помогает).

## Онлайн-реализация — `src/nirs/online.py` (`OnlineNirsDecoder`)

- **Состояние:** zi фильтров 4 банков × HbO/HbR; история производных каналов (≈7 МБ/сессию,
  для признаков нужны последние 12 с); суммы для std блока 1; буфер сырых признаков окон,
  для которых вызывался `predict`; 12 обученных sLDA.
- `push(hbo, hbr, frames)` — фильтрация новых отсчётов, пополнение истории.
- `predict(end)` — признаки 12 членов по отсчётам с `frame ≤ end`, сохранение в буфер,
  P(1,2,3) (до первого `fit_block` → None).
- `fit_block(states, offset)` — States завершённого блока (частота ЭЭГ) → разметка буферных
  окон (однородные, State>0); на первом вызове замораживается масштаб; переобучение 12 sLDA
  на всех размеченных окнах сессии.
- **Проверка/время** (`src/nirs/simulate_online.py`, 1 поток): онлайн = оффлайн
  (max |ΔP| ≈ 3e-5, совпадение argmax 99.7–100 %); `predict` медиана 3.8 мс, p99 6 мс;
  `fit_block` медиана 0.21 с, максимум 0.34 с (блок 7) — в лимитах 0.2 с / 1.5 с с запасом.

## Нейрофизиология (ERA по 54 сессиям, `std`-нормированный сигнал 0.01–0.3 Гц)

- HbO латерализация контралатеральна: левая кисть → правое полушарие ↑ (L−R ≈ −0.1 std),
  правая → левое ↑ (+0.08 std). Начало ~3 с, пик 8–12 с после начала сегмента, держится
  до ~15 с (т.е. захватывает следующий сегмент покоя).
- HbR — слабая и неустойчивая латерализация; кросс-субъектно HbR для L/R ≈ шанс (AUC 0.51–0.52),
  HbO — AUC 0.58 (общий для участников контралатеральный паттерн).
- Глобальный (системный) HbO: подъём ~+0.15 std через 4–5 с после начала сегмента и провал
  к 9–10 с в задаче; главный источник различения покой/задача.
- Из-за задержки первые ~3 с сегмента несут информацию о предыдущем сегменте — поэтому L/R
  учится только на окнах ≥ 3 с от начала сегмента.
