# stage0 — базовые модели на кэше признаков

- **Дата:** 2026-09-22. Окружение `kaggle` (python 3.11).
- **Признаки:** `python -m src.features.build_cache --win 1.0` → `data/features/v1_win1/*.npz`.
  - ЭЭГ: HP 1 Гц + notch 50 Гц (причинно, `sosfilt`), 6 полос Баттерворта 4-го порядка
    (4-8, 8-12, 12-16, 16-20, 20-26, 26-32 Гц), ковариации в окне 1 с.
    `ts` — касательное пространство с референсом = среднее по блоку 1 (1386 признаков);
    `logvar` — log-дисперсии каналов по полосам (126).
  - NIRS: НЧ 0.5 Гц; уровень после HP 0.01 Гц + разности с лагами 1/2/4/6 с для HbO и HbR
    (180 признаков).
  - `*_z` — z-нормировка по статистикам блока 1.
- **Протокол:** для блоков 2–7 модель обучается на блоках < b текущей сессии
  (± пул других участников, leave-subject-out); метрики по ТЗ §5.1, среднее по сессиям.
  Сетка окон — глобальная с шагом 62.5 отсчёта (оценка, реальный `run.py` не выдан).

## Результаты

| модель | minF1 | recall | 60F+30P |
|---|---|---|---|
| within, ЭЭГ `ts`, sLDA | 0.417 | 0.561 | 41.9 |
| within, ЭЭГ `logvar`, sLDA | 0.424 | 0.555 | 42.1 |
| within, NIRS, sLDA (54 сессии) | 0.388 | 0.533 | 39.3 |
| LOSO, ЭЭГ `logvar_z`, LR | 0.259 | 0.462 | 29.4 |
| LOSO, NIRS `nirs_z`, LR | 0.114 | 0.355 | 17.5 |
| within ЭЭГ + LOSO ЭЭГ (среднее вероятностей) | 0.418 | 0.556 | 41.7 |
| **within ЭЭГ + within NIRS (среднее вероятностей)** | **0.447** | **0.593** | **44.6** |

Выводы: основной источник качества — данные текущей сессии; кросс-субъектный пул в лоб не
помогает; объединение ЭЭГ+NIRS даёт +2.5 балла. Уровень эталона ТЗ (recall 53–57 %) достигнут.
Вероятности: `data/probs_stage0.pkl`.
